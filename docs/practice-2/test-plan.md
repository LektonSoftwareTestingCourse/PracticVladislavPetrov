# Тестовый план СМП

## 1. Область и подход

Объект тестирования: СМП по [архитектуре](../architecture.md). Подробные проверки относятся к авторизации и управлению картами, остальные сервисы проверяются по [чек-листам](checklists.md). Сначала готовятся отдельные карты и счётчики, затем выполняются дымовые проверки, проверки ядра и критический путь. Суммы указаны в копейках.

## 2. Критерии входа и выхода

**Вход:** согласованы ТЗ и описание интерфейсов, сервисы и зависимости проходят проверку работоспособности, тестовые карты и исходные данные воспроизводимы.

**Выход:** выполнены все проверки P0 и не менее 95% проверок ядра, нет открытых дефектов P0/P1, пройдены дымовые проверки и критический путь, каждая допустимая пара PICT представлена в обоих наборах. Это плановые критерии, результаты прогона здесь не заявлены.

**Приостановка:** недоступно ядро или БД, невозможно подготовить данные либо дефект P0 делает дальнейший прогон недостоверным. **Возобновление:** восстановить среду, повторить дымовые и затронутые проверки на чистых данных.

## 3. Ресурсы и расписание

Ответственный за подготовку работы: владелец репозитория. Для неё нужны ТЗ, описание интерфейсов и PICT. Docker Desktop, СМП, PostgreSQL, RabbitMQ, программа для отправки запросов и синтетические карты понадобятся при выполнении запланированных проверок. К [сроку 25.09.2026](https://github.com/LektonSoftwareTestingCourse/Lectures/blob/main/materials/module-02-test-design/practice/practice-01.md) должны быть готовы четыре документа, два попарных набора и самопроверка. Фактический прогон не входит в состав этой работы.

## 4. Риски и метрики

Риски: общий баланс или накопленный расход могут исказить следующую проверку, поэтому для каждой нужны отдельные исходные данные. Запись в журнале транзакций появляется не сразу, поэтому поиск требует ожидания. Правило срока в текущем месяце и часть кодов отказа требуют уточнения.

Метрики: доля пройденных проверок по приоритетам, открытые дефекты P0/P1, покрытие классов и границ, покрытие допустимых пар, пройденные пункты чек-листов.
