# Чек-листы СМП

Пункты не отмечены, поскольку это план, а не результат прогона. Подробные проверки авторизации и управления картами находятся в [тест-дизайне](test-design.md).

## 1. Дымовое тестирование

- [ ] PostgreSQL, RabbitMQ и сервисы запущены, проверки работоспособности проходят.
- [ ] Шлюз и маршрутизатор принимают и направляют запрос.
- [ ] Справочник BIN и сервис уведомлений доступны.
- [ ] Симуляторы терминала и торговой точки отправляют транзакции.
- [ ] Журнал транзакций получает событие, панель мониторинга загружается.
- [ ] Покупка активной картой возвращает ответ.

## 2. Критический путь

- [ ] Шлюз отклоняет некорректный запрос, маршрутизатор различает известный и неизвестный BIN.
- [ ] Оба симулятора получают согласованный ответ по покупке.
- [ ] Допустимая покупка уменьшает баланс один раз.
- [ ] Заблокированная, просроченная карта и превышение лимита не резервируют средства.
- [ ] При недоступном справочнике BIN работает резервный маршрут.
- [ ] RabbitMQ доставляет результат в журнал, запись видна на панели мониторинга.
- [ ] Событие карты доходит до сервиса уведомлений и не меняет решение авторизации.
